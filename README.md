# 🏆 MÜLK Spor Kulübü - Web Sitesi

Ankara'da çocuklar ve gençler için okul salonlarında futbol, basketbol, voleybol ve yüzme branşlarında spor eğitimi sunan **MÜLK Spor Kulübü** resmi web sitesi.

---

## 📌 Özellikler

- **Mobil ve Masaüstü Uyumlu (Responsive):** Telefon, tablet ve bilgisayarlarda kusursuz görünüm.
- **Modern ve Temiz Tasarım:** Kulübün kimliğine uygun renk paleti, görsel düzen ve akıcı geçişler.
- **İnteraktif Branş ve Program Takvimi:** Branşlara göre ayrılmış antrenman sekmeleri.
- **Sıkça Sorulan Sorular (SSS):** Açılır-kapanır soru-cevap bölümü.
- **Hafif ve Hızlı:** Ek kütüphane veya ağır framework'ler olmadan saf HTML5, CSS3 ve modern JavaScript ile yüksek performans.
- **SEO ve Sosyal Medya Uyumlu:** Meta etiketleri, Open Graph tanımları ve `robots.txt` ile arama motorlarına hazır.

---

## 🚀 Yerel Olarak Çalıştırma

Bu projeyi bilgisayarınızda görüntülemek için:
1. `index.html` dosyasına çift tıklayarak herhangi bir internet tarayıcısında (Chrome, Safari, Edge, Firefox vb.) doğrudan açabilirsiniz.
2. Veya yerel bir web sunucusu ile çalıştırmak isterseniz:
   ```bash
   # Python ile
   python3 -m http.server 8000
   ```
   Ardından tarayıcınızda `http://localhost:8000` adresine gidebilirsiniz.

---

## 🌐 GitHub Pages ile Ücretsiz Yayınlama Adımları

1. Bu depoyu (repository) GitHub hesabınıza yükleyin (`main` dalında).
2. GitHub reponuzda üst kısımdaki **Settings** (Ayarlar) sekmesine tıklayın.
3. Sol menüden **Pages** seçeneğine girin.
4. **Build and deployment** > **Branch** bölümünde `main` ve `/ (root)` seçin, ardından **Save** (Kaydet) butonuna tıklayın.
5. 1-2 dakika sonra siteniz `https://<kullanici-adiniz>.github.io/<repo-adiniz>/` adresinde herkese açık olarak yayına girecektir.
